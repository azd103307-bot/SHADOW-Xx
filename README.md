# SHADOW AI

مركز عربي موحّد لأدوات الذكاء الاصطناعي، كتطبيق Android يعمل بواجهة WebView محلية.

## المزايا الحالية

- محادثة عربية متعددة الأدوار مع نماذج متوافقة مع OpenAI Chat Completions.
- إعداد عنوان API ومفتاح خاص واختيار النموذج.
- اكتشاف قائمة النماذج النصية المتاحة من الخادم.
- استوديو صور عبر واجهة Images Generations المتوافقة.
- مساعد برمجة لإنشاء الأكواد وشرحها وإصلاحها.
- الكاتب الذكي والترجمة السياقية.
- تحليل ملفات TXT وMD وCSV وJSON وHTML وXML.
- الإملاء الصوتي وقراءة النص عبر ميزات المتصفح والجهاز.
- حفظ الإعدادات وسجل المحادثة محلياً.
- تطبيق وِرد محفوظ في `app/src/main/assets/quran.html` ويمكن فتحه من داخل التطبيق.

## بناء APK

يبدأ GitHub Actions بناء APK تلقائياً عند كل تحديث إلى `main` أو يدوياً:

1. افتح تبويب **Actions**.
2. اختر **Build SHADOW AI Android APK**.
3. افتح آخر تشغيل ناجح.
4. نزّل Artifact باسم `SHADOW-AI-Android-APK`.
5. فك ملف ZIP وثبّت `app-debug.apk` على Android.

الملف الناتج Debug APK للاختبار، وليس إصدار متجر موقّعاً.

## إعداد مزوّد الذكاء الاصطناعي

افتح التطبيق ثم **الإعدادات**، وأدخل عنوان API الأساسي ومفتاحك الخاص. الإعداد الافتراضي هو:

```
https://gen.pollinations.ai/v1
```

يمكن استخدام خادم آخر متوافق مع OpenAI Chat Completions بتغيير العنوان والنموذج. استخدم زر **تحميل النماذج** لاكتشاف النماذج النصية التي يعرضها الخادم، ثم اختبر الاتصال.

**مهم:** لا يحتوي التطبيق على مفاتيح API مضمّنة ولا يستطيع إنشاء مفتاح أو رصيد نيابة عن المستخدم. وثائق Pollinations الحالية تتطلب مفتاحاً صالحاً لطلبات التوليد؛ وقد تختلف الأسعار والصلاحيات وحدود الاستخدام حسب النموذج والحساب. لا تفترض أن كل نموذج مجاني. لا تضع مفتاحك في ملفات المستودع أو تشاركه مع أحد.

المفتاح الذي تدخله يُحفظ محلياً في مساحة تخزين التطبيق على جهازك. احذفه من الإعدادات قبل تسليم الجهاز لشخص آخر، ولا ترسل ملفات حساسة إلى مزوّد خارجي.

## حدود الإصدار

- ملفات المستندات المدعومة حالياً: TXT وMD وCSV وJSON وHTML وXML. ملفات PDF وDOCX تحتاج استخراج النص قبل الإرفاق.
- الإملاء والقراءة الصوتية يعتمدان على دعم المتصفح والأصوات المثبتة على الجهاز.
- إنشاء الصور يعمل فقط إذا كان مزوّد API يتيح واجهة الصور والنموذج المختار.
- لا يتضمن هذا المستودع خادماً لتشغيل نماذج ضخمة محلياً، ولا يتجاوز حدود الخطط المجانية أو اشتراطات مزوّدي النماذج.

## بنية المشروع

- `app/src/main/assets/index.html` — واجهة SHADOW AI.
- `app/src/main/assets/quran.html` — تطبيق وِرد للمصحف.
- `app/src/main/java/com/ward/quran/` — غلاف Android ومستقبل التذكير.
- `.github/workflows/android-apk.yml` — بناء APK تلقائياً.
