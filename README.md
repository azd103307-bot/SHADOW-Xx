# MANSER AI – مانسر

تطبيق Android لإنشاء الفيديوهات بالذكاء الاصطناعي عبر محرك MoneyPrinterTurbo.

## ما الذي يقدمه؟
- واجهة عربية RTL بألوان برتقالي وأحمر.
- إنشاء فيديو من فكرة أو نص تكتبه.
- اختيار المقاس: عمودي 9:16 أو أفقي 16:9 أو مربع 1:1.
- متابعة حالة التوليد وعرض روابط الفيديو الناتج.
- إعداد عنوان خادم MoneyPrinterTurbo ومفتاح API من داخل التطبيق.
- تطبيق Android حقيقي يفتح واجهته محلياً، وليس صفحة ويب مستضافة.

## تشغيل المحرك
يجب تشغيل MoneyPrinterTurbo على خادم يمكن للهاتف الوصول إليه. أدخل عنوان الخادم الأساسي في إعدادات التطبيق، مثال:
http://192.168.1.10:8080

يجب أن يدعم الخادم المسار POST /api/v1/videos والمسار GET /api/v1/tasks/{task_id}. إذا كان الخادم يستخدم API Key فضعه في إعدادات التطبيق. لا تضع مفاتيحك السرية في ملفات المستودع.

المشروع لا يستضيف محرك توليد الفيديو ولا يتضمن مفاتيح خدمات مدفوعة. الصوت العربي يعتمد على الأصوات ومزود TTS المثبتين والمهيئين في خادم MoneyPrinterTurbo.

## بناء APK
يبدأ GitHub Actions بناء APK تلقائياً بعد كل تحديث إلى main:
1. افتح تبويب Actions.
2. اختر Build MANSER AI Android APK.
3. افتح آخر عملية ناجحة ونزّل Artifact باسم MANSER-AI-Android-APK.
4. فك ملف ZIP وثبّت app-debug.apk على Android.

النسخة الناتجة Debug APK للتجربة وليست إصدار متجر موقّعاً.
