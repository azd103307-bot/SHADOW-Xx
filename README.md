# SHADOW Xx — SHADOW BUILD

تطبيق أندرويد باللغة العربية. يتضمن مساحة عمل للبناء والتشييد ثلاثية الأبعاد، مستقلة عن أي دروس أو شخصية افتراضية؛ المستخدم هو من ينشئ القطع ويشرح مشروعه.

## مساحة البناء الحالية
- مشهد ثلاثي الأبعاد مبني بـ OpenGL ES مع تدوير المنظور والتقريب بإصبعين.
- إضافة بلوكات وألواح ومربعات خشبية ودعامات وقوالب.
- أطوال خشب سريعة: 3 م، 1.5 م، 1 م، و75 سم.
- تفعيل/إيقاف علامة التثبيت والتسمير للقطع الجديدة.
- تحديد آخر قطعة، نسخها، تدويرها، وحذفها، مع التراجع وإعادة الإضافة ومسح المشهد.
- إظهار/إخفاء شبكة القياس.
- حفظ آخر مشروع محلياً وفتحه.
- حاسبة تمتير يدوية لمساحة الجدار والحجم وعدد بلوك تقديري.
- إنشاء تقرير كميات نصي ونسخه.

## الاستخدام
افتح التطبيق ثم اختر «افتح ورشة البناء ثلاثية الأبعاد». المس المشهد لإضافة القطع. اسحب بإصبع واحد لتدوير المنظور، واستخدم إصبعين للتقريب والتبعيد.

## البناء
يفتح المشروع في Android Studio أو يبنى عبر GitHub Actions من تبويب Actions. كل تحديث لملفات Kotlin أو Gradle أو XML على فرع main يشغّل بناء APK Debug ويرفعه كـ Artifact باسم SHADOW-Xx-debug.

## حدود النسخة الحالية
هذه نسخة تطوير أولية موسعة وليست أداة هندسية معتمدة للتنفيذ الإنشائي. التمتير اليدوي حالي، وعدد البلوك تقديري ولا يشمل تفاصيل الفواصل أو الفتحات أو الهدر. تصدير صورة المشهد، تحرير أي قطعة باختيار مباشر، التحديد المرئي المتقدم، مخططات CAD، مزامنة المشاريع، وكاميرا الواقع المعزز تحتاج تطويراً واختباراً لاحقاً. لا تستخدم النتائج بديلاً عن مراجعة مهندس مختص.
