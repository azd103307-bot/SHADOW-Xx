# SHADOW Xx
تطبيق أندرويد بشريط أدوات عائم: الرئيسية، رجوع، قفل الشاشة، استخراج النص المتاح من واجهة التطبيق ونسخه، وتشغيل تطبيقين يختارهما المستخدم.

## البناء
يفتح المشروع في Android Studio أو يبنى عبر GitHub Actions من تبويب Actions.
فعّل خدمة SHADOW Xx من إعدادات إمكانية الوصول حتى يعمل الشريط.
ملاحظة: استخراج النص يعتمد على عقد واجهة إمكانية الوصول؛ لا يقرأ الصور أو النصوص المرسومة داخل صورة، وقد تمنع بعض التطبيقات الوصول إلى محتواها.
