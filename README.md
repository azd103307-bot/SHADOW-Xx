# وِرد – القرآن الكريم

تطبيق ويب عربي تقدمي للقراءة فقط دون أصوات.

- المصحف بالرسم العثماني عبر AlQuran Cloud API.
- يتحقق التطبيق من 114 سورة و6236 آية قبل الحفظ المحلي.
- العلامات والملاحظات وآخر موضع قراءة تحفظ محليًا على الجهاز.
- أول تحميل يحتاج اتصالًا بالإنترنت. يتطلب تثبيت PWA استضافة HTTPS.
- لا يحتوي على تلاوة صوتية أو موسيقى.

الملفات: index.html التطبيق، manifest.webmanifest بيانات التثبيت، sw.js تخزين غلاف التطبيق.
