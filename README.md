# SHADOW AI

مركز عربي موحّد لأدوات الذكاء الاصطناعي، كتطبيق Android يعمل بواجهة WebView محلية.

## المزايا الحالية

- محادثة عربية متعددة الأدوار مع نماذج متوافقة مع OpenAI Chat Completions، مع تحليل الصور الملتقطة بالكاميرا أو المختارة من المعرض عبر نماذج الرؤية.
- إعداد عنوان API والنموذج الافتراضي واكتشاف كتالوج النماذج النصية والصورية.
- استوديو صور عبر واجهة Images Generations المتوافقة.
- توليد فيديو وملفات صوتية ومجسمات ثلاثية الأبعاد عند دعم المزوّد.
- مساعد برمجة لإنشاء الأكواد وشرحها وإصلاحها.
- الكاتب الذكي والترجمة السياقية.
- تحليل ملفات TXT وMD وCSV وJSON وHTML وXML، مع منتقي ملفات أصلي في Android.
- إرفاق الصور أو التقاطها بالكاميرا من شاشة المحادثة وتحليلها بنموذج يدعم الرؤية.
- الإملاء الصوتي، تفريغ الملفات الصوتية إلى نص، وقراءة النص عبر ميزات المتصفح والجهاز.
- أرشيف محادثات متعدد قابل للبحث، مع نسخ احتياطي واستعادة بصيغة JSON.
- حفظ الإعدادات والمحادثات محلياً على الجهاز.
- تطبيق وِرد محفوظ في `app/src/main/assets/quran.html` ويمكن فتحه من داخل التطبيق.

## بناء APK

يبدأ GitHub Actions بناء APK تلقائياً عند كل تحديث إلى `main` أو يدوياً:

1. افتح تبويب **Actions**.
2. اختر **Build SHADOW AI Android APK**.
3. افتح آخر تشغيل ناجح.
4. نزّل Artifact باسم `SHADOW-AI-Android-APK`.
5. فك ملف ZIP وثبّت `app-debug.apk` على Android.

الملف الناتج Debug APK للاختبار، وليس إصدار متجر موقّعاً. الإصدار الحالي 1.3.0.

## إعداد مزوّد الذكاء الاصطناعي

افتح التطبيق ثم **الإعدادات**، وأدخل عنوان خادم متوافقاً مع OpenAI Chat Completions والنموذج الذي يتيحه الخادم. العنوان الافتراضي في الواجهة:

```
https://gen.pollinations.ai/v1
```

يمكن استخدام خادم آخر متوافق بتغيير العنوان. استخدم زر **تحميل النماذج** لاكتشاف النماذج النصية والصورية والفيديو المتاحة إذا كان الخادم يوفّر كتالوج Pollinations، ثم اختبر الاتصال.

**حدود مهمة:** لا يحتوي التطبيق على مفاتيح API مضمّنة ولا يستطيع إنشاء حساب أو مفتاح أو رصيد نيابة عن المستخدم. طلبات التوليد السحابية تحتاج اعتماداً صالحاً من المزوّد، وقد تكون مدفوعة أو محدودة حسب النموذج والحساب. لا تفترض أن النموذج مجاني لمجرد ظهوره في القائمة.

**أمان المفاتيح:** لا تلصق مفتاح خادم دائم أو مفتاحاً سرياً طويل العمر داخل تطبيق عميل. Pollinations يوجّه تطبيقات الويب والهاتف إلى Pollinations Pay / BYOP للحصول على رمز مستخدم محدود الصلاحية، ويتطلب ذلك تسجيل App Key وتفويض المستخدم؛ تدفق OAuth هذا غير منفذ بعد في هذا الإصدار. يمكن بدلاً من ذلك استخدام خادم وسيط آمن تديره أنت، مع إبقاء المفتاح السري على الخادم. لا تضع أي مفتاح في ملفات المستودع أو تشاركه.

الرمز الذي تدخله في الواجهة يُحفظ محلياً على الجهاز. راجع سياسة مزوّدك قبل إرسال بيانات خاصة، واحذف بيانات التطبيق قبل تسليم الجهاز لشخص آخر.

## حدود الإصدار

- ملفات المستندات المدعومة حالياً: TXT وMD وCSV وJSON وHTML وXML. ملفات PDF وDOCX تحتاج استخراج النص قبل الإرفاق.
- الإملاء والقراءة الصوتية يعتمدان على دعم المتصفح والأصوات المثبتة على الجهاز.
- إنشاء الصور والفيديو والصوت والمجسمات يعمل فقط إذا كان خادم API يتيح المسارات والنماذج المختارة.
- لا يتضمن هذا المستودع خادماً لتشغيل نماذج ضخمة محلياً، ولا يتجاوز حدود الخطط المجانية أو اشتراطات مزوّدي النماذج.

## بنية المشروع

- `app/src/main/assets/index.html` — واجهة SHADOW AI.
- `app/src/main/assets/quran.html` — تطبيق وِرد للمصحف.
- `app/src/main/java/com/ward/quran/` — غلاف Android ومستقبل التذكير.
- `.github/workflows/android-apk.yml` — بناء APK تلقائياً.
