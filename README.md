# SHADOW BUILD — ورشة البناء

الإصدار التطويري الحالي: **1.2.0**.

تطبيق أندرويد عربي لمساحة عمل حرة للبناء والتشييد. التطبيق مخصص للبناء والتشييد فقط، ولا توجد شخصية افتراضية أو دروس مفروضة؛ المستخدم هو من يضيف القطع ويكوّن النموذج ويكتب شرحه.

## الوظائف الموجودة في نسخة التطوير
- مساحة ثلاثية الأبعاد باستخدام OpenGL ES.
- تدوير المنظور بإصبع واحد، والتقريب والتبعيد بإصبعين، ووضع القطع على أرضية المشهد بإسقاط شعاع اللمس على مستوى الأرض.
- مناظير جاهزة: منظور عام، علوي، أمامي، جانبي.
- أرضية عمل بمساحة 60×60 متراً، وشبكة قياس بفواصل 50 سم قابلة للإظهار والإخفاء، ومحاذاة اختيارية إلى 10 سم.
- لوحة ألوان للقطع مع تطبيق اللون على القطعة المحددة.
- إضافة بلوك وطوب وصفوف، وإنشاء جدار بمقاسات يحددها المستخدم مع رصّ متبادل للمداميك وفواصل مونة وفتحة وسطية لباب أو نافذة مع كمرة علوية تمثيلية، إضافة إلى ألواح ومربعات خشبية ودعامات وقوالب صب وأعمدة وكمرات وبلاطات خرسانية.
- مقاسات خشب سريعة: 3 م، 1.5 م، 1 م، 75 سم، ومربع 7×7 سم.
- تحديد القطعة من حدودها المرئية باللمس، تمييزها بصرياً، سحبها، نسخها، تدويرها، رفعها وخفضها، وضع قطعة فوق أخرى، حذفها، وتعديل أبعادها.
- تراجع وإعادة لبعض تغييرات النموذج.
- علامة تثبيت/تسمير مرئية للقطع الجديدة؛ وهي تمثيل بصري وليست محاكاة ميكانيكية للمسامير.
- حفظ تلقائي واستعادة آخر عمل، حفظ مشاريع متعددة بأسماء، فتحها وحذفها، وحفظ نسخة سريعة أو استيراد/تصدير ملف مشروع JSON عبر مدير ملفات أندرويد.
- كتابة شرح وخطوات للمشروع (كل خطوة في سطر مستقل)، وحفظها ضمن ملفه وعرضها للآخرين خطوة بخطوة، مع تضمينها في التقرير.
- حاسبة تمتير للجدار تشمل الفتحات، مقاس البلوك، فاصل المونة، العدد التقريبي، الحجم، تقدير الإسمنت والرمل، وتكلفة البلوك والإسمنت والرمل وفق الأسعار التي يدخلها المستخدم، مع حاسبة تكلفة منفصلة للنموذج تشمل الطوب والخشب والخرسانة.
- إنشاء تقرير كميات نصي ونسخه أو مشاركته.
- حفظ صورة PNG للمشهد ثلاثي الأبعاد في معرض الصور.
- تصدير مخطط علوي ثنائي الأبعاد بصيغة DXF، وتصدير هندسة النموذج ثلاثي الأبعاد بصيغة OBJ لفتحها في برامج CAD و3D؛ الإحداثيات بالمتر.
- التقاط صورة بالكاميرا أو اختيار صورة موجودة، ثم قياس المسافات يدوياً بين نقطتين على أرضية المشهد ثلاثي الأبعاد، أو معايرة صورة بطول مرجعي معروف؛ قياس الصورة تقريبي ويتأثر بمنظور التصوير.

## تشغيل المشروع وبناء APK
- افتح المشروع في Android Studio أو استخدم GitHub Actions.
- كل تحديث لملفات Kotlin أو Gradle أو XML على الفرع الرئيسي يشغّل بناء Debug.
- يحاول خط البناء تشغيل اختبار واجهة داخل محاكي أندرويد؛ إذا تعذر تشغيل المحاكي، لا يمنع ذلك نشر APK الذي اجتاز البناء.
- بعد نجاح مهمة إنشاء APK يُرفع ملف التثبيت كأثر باسم SHADOW-BUILD-debug من صفحة Actions.

## ما لا ينبغي اعتباره مكتملاً بعد
هذه النسخة ليست بعد برنامجاً هندسياً احترافياً أو بديلاً عن برامج CAD أو مراجعة المهندس. ما زالت تحتاج إلى اختبارات فعلية على أجهزة أندرويد مختلفة، وتحسين دقة اختيار القطع ووضعها فوق بعضها، ونظام طبقات/محاذاة وقياسات ثلاثية الأبعاد احترافية، وتوسيع تصدير CAD إلى مخططات تنفيذية أكثر تفصيلاً، وتفاصيل النجارة والتسمير، وتوسيع مكتبة المواد، وتحسين تقارير الكميات والتكاليف، وتجربة واقع معزز بالكاميرا عند دعم الجهاز. قياس الصورة الحالي ليس قياساً حياً ولا يصحح تشوه المنظور تلقائياً. حاسبة البلوك تقديرية؛ نسبة الهدر الحالية تطبق على عدد البلوك فقط ولا تغطي فاقد المونة أو تفاصيل التنفيذ والاشتراطات الإنشائية.

لا تستخدم أي قياسات أو نتائج تقديرية للتنفيذ الإنشائي قبل مراجعة مختص.
