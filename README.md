# وِرد – تطبيق المصحف الشريف لأندرويد

تطبيق Android أصلي بواجهة قراءة عربية داخل WebView، وليس مطلوبًا فتحه كموقع.

## الميزات
- المصحف بالرسم العثماني، مع التحقق من وجود 114 سورة و6236 آية.
- فهرس السور والبحث والعلامات والملاحظات وحفظ آخر موضع قراءة.
- وضع ليلي وخطة ختمة بسيطة.
- قراءة فقط: لا توجد تلاوة صوتية أو موسيقى.
- يحفظ نص المصحف محليًا بعد تنزيله لأول مرة؛ أول تشغيل يحتاج اتصالًا بالإنترنت.

## بناء APK
يُبنى ملف التثبيت التجريبي تلقائيًا بواسطة GitHub Actions عند الدفع إلى الفرع الرئيسي.
1. افتح تبويب **Actions** في المستودع.
2. اختر **Build Android APK** وانتظر حتى تظهر علامة نجاح خضراء.
3. افتح عملية البناء الناجحة، ثم قسم **Artifacts**.
4. نزّل `Ward-Quran-Android-APK` وافتح ملف ZIP، ثم ثبّت `app-debug.apk` على هاتف Android.

هذا APK تجريبي غير موقّع للنشر على المتجر. قد يطلب Android السماح بالتثبيت من هذا المصدر.
