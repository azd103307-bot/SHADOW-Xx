# SHADOW BUILD — ورشة البناء

تطبيق أندرويد عربي لمساحة عمل حرة للبناء والتشييد. لا توجد شخصية افتراضية أو دروس مفروضة؛ المستخدم هو من يضيف القطع ويكوّن النموذج ويكتب شرحه.

## الوظائف الموجودة في نسخة التطوير
- مساحة ثلاثية الأبعاد باستخدام OpenGL ES.
- تدوير المنظور بإصبع واحد، والتقريب والتبعيد بإصبعين.
- مناظير جاهزة: منظور عام، علوي، أمامي، جانبي.
- شبكة قياس أرضية قابلة للإظهار والإخفاء، ومحاذاة اختيارية إلى 10 سم.
- لوحة ألوان للقطع مع تطبيق اللون على القطعة المحددة.
- إضافة بلوك، صف بلوكات، جدار متعدد الطبقات، ألواح خشبية، مربعات خشبية، دعامات، وقوالب صب.
- مقاسات خشب سريعة: 3 م، 1.5 م، 1 م، 75 سم، ومربع 7×7 سم.
- تحديد القطعة باللمس، تمييزها بصرياً، سحبها، نسخها، تدويرها، رفعها وخفضها، وضع قطعة فوق أخرى، حذفها، وتعديل أبعادها.
- تراجع وإعادة لبعض تغييرات النموذج.
- علامة تثبيت/تسمير مرئية للقطع الجديدة؛ وهي تمثيل بصري وليست محاكاة ميكانيكية للمسامير.
- حفظ مشروع باسم، فتح المشاريع المحفوظة وحذفها، حفظ نسخة سريعة، واستيراد/تصدير ملف مشروع JSON عبر مدير ملفات أندرويد.
- كتابة شرح وخطوات للمشروع وحفظها ضمن ملفه، مع تضمينها في التقرير.
- حاسبة تمتير للجدار تشمل الفتحات، مقاس البلوك، فاصل المونة، العدد التقريبي، الحجم، والتكلفة وفق السعر الذي يدخله المستخدم.
- إنشاء تقرير كميات نصي ونسخه أو مشاركته.
- حفظ صورة PNG للمشهد ثلاثي الأبعاد في معرض الصور.
- التقاط صورة بالكاميرا أو اختيار صورة موجودة، ثم قياس المسافات يدوياً بعد معايرتها بطول مرجعي معروف؛ النتائج تقريبية وتتأثر بمنظور التصوير.

## تشغيل المشروع وبناء APK
- افتح المشروع في Android Studio أو استخدم GitHub Actions.
- كل تحديث لملفات Kotlin أو Gradle أو XML على الفرع الرئيسي يشغّل بناء Debug.
- ينتج البناء ملف APK تجريبياً ضمن Artifact باسم SHADOW-Xx-debug.

## ما لا ينبغي اعتباره مكتملاً بعد
هذه النسخة ليست بعد برنامجاً هندسياً احترافياً أو بديلاً عن برامج CAD أو مراجعة المهندس. ما زالت تحتاج إلى اختبارات فعلية على أجهزة أندرويد مختلفة، وتحسين دقة اختيار القطع ووضعها فوق بعضها، ونظام طبقات/محاذاة وقياسات ثلاثية الأبعاد دقيقة، وتصدير مخطط هندسي بصيغ CAD، وتفاصيل النجارة والتسمير، وتوسيع مكتبة المواد، وتحسين تقارير الكميات والتكاليف، وتجربة واقع معزز بالكاميرا عند دعم الجهاز. قياس الصورة الحالي ليس قياساً حياً ولا يصحح تشوه المنظور تلقائياً. حاسبة البلوك الحالية تقديرية ولا تحسب الهدر والتفاصيل الإنشائية بالكامل.

لا تستخدم أي قياسات أو نتائج تقديرية للتنفيذ الإنشائي قبل مراجعة مختص.
