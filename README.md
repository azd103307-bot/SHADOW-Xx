# لصقتي – Lasaqti
تطبيق Android عربي لأدوات النسخ والحافظة والأزرار العائمة.

## البناء
افتح المشروع في Android Studio ثم نفّذ:
`gradle assembleDebug`
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## الاستخدام
1. ثبّت التطبيق وافتحه.
2. اضغط «تفعيل الأزرار العائمة» واسمح بالظهور فوق التطبيقات.
3. استخدم حقل النسخ داخل التطبيق.
4. للصق في تطبيق آخر: انسخ النص، افتح الحقل المطلوب، ثم اختر «لصق» من قائمة Android.

## حدود Android
لا يمكن لأي تطبيق عادي ضمان إدخال النص تلقائياً في كل تطبيق أو متصفح أو سطح مكتب افتراضي. الحقول المحمية وبعض الجلسات البعيدة قد تمنع اللصق.
