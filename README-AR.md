# SHADOW X Wi-Fi RECON — Android wrapper

هذا مشروع Android يضم ملف HTML المرفوع داخل WebView محلي. لا يحتاج التطبيق إلى اتصال إنترنت لتشغيل الواجهة نفسها.

## بناء APK عبر GitHub من الهاتف
1. أنشئ مستودعاً جديداً على GitHub وارفع جميع محتويات هذا المجلد إليه، مع الحفاظ على أسماء المجلدات.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build SHADOW X APK** ثم **Run workflow**.
4. بعد اكتمال البناء افتح نتيجة التشغيل ونزّل Artifact باسم **SHADOW-X-RECON-APK**.
5. فك ضغط الملف، ثم ثبّت `app-debug.apk` على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

## البناء محلياً
يتطلب Android SDK وJDK 17 وGradle، ثم نفّذ:
`gradle assembleDebug`

## حدود النسخة الحالية
- هذه حزمة WebView للواجهة الحالية؛ ليست إعادة كتابة أصلية لكل المحركات.
- اختيار ملفات PCAP/JSON يعمل من خلال منتقي ملفات Android المدمج.
- التخزين الحالي يعتمد على localStorage داخل WebView.
- لا يوجد حالياً اتصال حي بالراوتر أو التقاط حزم Wi-Fi من النظام. واجهات HTML وحدها لا تمنح هذه الصلاحيات.
- لا تُمنح صلاحيات حساسة غير لازمة. أضفنا فقط ما يلزم لتشغيل الواجهة وفتح الملفات التي يختارها المستخدم.
- البناء الناتج Debug للتجربة الشخصية، وليس إصداراً موقعاً للنشر العام.
