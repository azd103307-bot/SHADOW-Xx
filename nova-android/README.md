# نوفا – التمرد (Android)
مشروع Android WebView يعرض ملف HTML الأصلي داخل التطبيق. الحد الأدنى Android 8.0 (API 26).
يبنى ملف APK عبر GitHub Actions عند رفع تغييرات مجلد nova-android.
ملف APK الناتج: app/build/outputs/apk/debug/app-debug.apk
التسجيل يحاول حفظ فيديو WebM في Movies/Nova على Android عبر MediaStore.
